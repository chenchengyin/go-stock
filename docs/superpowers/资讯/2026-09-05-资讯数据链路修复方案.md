# 资讯数据链路修复方案

## 1. 当前问题与根因

当前服务器存在两份 SQLite 数据库：

```text
/root/go-stock/data/stock.db
/root/go-stock/backend/data/stock.db
```

服务从 `/root/go-stock` 启动，`db.Init("")` 最终使用的是：

```text
/root/go-stock/data/stock.db
```

这份数据库包含用户、登录会话和模块权限，但没有资讯相关表：

- `telegraph_list`
- `tags`
- `telegraph_tags`

旧资讯数据位于 `/root/go-stock/backend/data/stock.db`，当前有财联社和新浪财经历史数据。

现有代码的问题是：

1. 资讯接口只查询数据库，不会在查询为空或报错时请求网络。
2. 后台抓取任务虽然请求网络，但抓取结果优先写数据库。
3. 数据库表不存在时，部分查询和写入错误被忽略。
4. Flutter 收到空列表后只能展示“暂无数据”。

因此当前表现是资讯子系统失效，但 Go 服务进程本身仍然正常。

## 2. 第一阶段：立即恢复资讯数据

### 2.1 保留当前主数据库

不覆盖 `/root/go-stock/data/stock.db`，因为其中包含：

- 用户账号
- 登录会话
- 管理员会话
- 模块权限
- 用户自选和交易数据

### 2.2 迁移资讯相关表

只从旧数据库迁移以下内容：

- `tags`
- `telegraph_list`
- `telegraph_tags`

迁移前备份当前主数据库。迁移完成后验证：

- 资讯表存在
- 历史资讯记录数量正常
- 财联社和新浪财经均能查询到数据
- `/api/news` 和 `/api/news/domestic` 返回非空结果

### 2.3 后端自动建表

`flutter_api.AutoMigrate()` 纳入资讯模型：

- `models.Tags`
- `models.Telegraph`
- `models.TelegraphTags`

这样后续即使部署到一份全新的 SQLite 数据库，也会自动创建基础资讯表，不再因为缺表导致资讯链路失效。

## 3. 第二阶段：服务端网络优先与缓存兜底

数据库只作为缓存，不作为资讯展示的唯一来源。

### 3.1 服务端抓取

由服务端后台任务统一负责网络抓取：

- 服务启动时执行一次
- 每 30～60 秒执行一次
- 财联社、新浪、外媒分别处理
- 使用单例锁，保证同一时间只有一个抓取任务
- 某个来源失败不影响其他来源

普通客户端不负责触发网络抓取，避免多个用户同时打开页面时造成重复请求和外部接口限流。

### 3.2 接口返回策略

资讯接口按照以下顺序处理：

```text
读取短时缓存
  ↓ 命中且未过期：直接返回
  ↓ 未命中、过期或缓存异常
读取最后一次成功缓存
  ↓ 有缓存：返回旧数据并标记正在更新
  ↓ 无缓存：等待服务端后台任务或返回明确的加载状态
```

网络抓取成功后，先更新内存/文件缓存，再异步写数据库。数据库写入失败不能影响本次网络结果返回。

### 3.3 失败处理

不再把以下情况静默转换成空列表：

- 数据库表不存在
- 数据库查询失败
- 网络请求超时
- 单个资讯来源返回异常

服务端记录错误，接口返回可识别的状态；Flutter 展示“资讯暂时无法更新”和重试入口。

## 4. 第三阶段：Flutter 资讯 Tab 行为

Flutter 每次从其他底部 Tab 进入“市场快讯”时：

1. 向服务端重新读取一次资讯缓存。
2. 不直接触发外部网络抓取。
3. 保留“重要、国内资讯、热门话题、外媒”的内部 Tab 状态。
4. 用户点击右上角刷新按钮时，再执行一次强制读取。

这里的“每次进入刷新”是客户端刷新服务端数据视图，不是让每个客户端触发一次外部抓取。

## 5. 部署与回滚

### 部署内容

- 重新构建并上传 `go-stock-server`
- 执行资讯表和数据的单次迁移
- 重启 Go 服务
- Flutter Web 和管理后台没有参与第一阶段数据恢复，不需要因数据库迁移重新构建

### 回滚内容

保留迁移前的主数据库备份和旧后端二进制。若迁移验证失败：

1. 停止服务。
2. 恢复旧二进制。
3. 恢复主数据库备份。
4. 重启并检查 `/api/health`。

## 6. 验收标准

- 服务器重启后资讯表仍然存在。
- `/api/news?source=财联社电报` 返回资讯列表。
- `/api/news?source=新浪财经` 返回资讯列表。
- `/api/news/domestic` 返回合并后的国内资讯。
- 资讯表写入失败时，接口仍能返回网络或缓存数据。
- 客户端每次进入市场快讯都会重新读取服务端数据。
- 多个客户端同时进入时，不会触发多次外部抓取。
