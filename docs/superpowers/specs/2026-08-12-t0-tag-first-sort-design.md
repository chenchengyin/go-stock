# 主板策略标记优先排序设计

## 目标

所有返回客户端的主板策略股票列表中，有标记的股票排在无标记股票前面；两组内部继续按 `T0开盘涨幅(%)` 从高到低排序。

## 实现

- 后端新增纯函数 `sortT0ResultsForClient([]T0SelectionResult) []T0SelectionResult`。
- 函数复制输入切片后稳定排序，不修改归档或调用方原切片。
- 排序键依次为：
  1. `标记` 非空优先；
  2. `T0开盘涨幅(%)` 降序；
  3. 两项相同时保持原顺序。
- 下列返回入口统一调用该函数：
  - 当天正式选股响应；
  - 凌晨预热完成后的前日归档响应；
  - `archived=1` 历史归档响应；
  - `refresh_close=1` 与 `refresh_tags=1` 的结果响应。
- 磁盘 selection JSON 不因展示排序而重写。

## 测试

- 有标记结果排在无标记结果之前。
- 两组内部均按开盘涨幅降序。
- 相同排序键保持原顺序。
- 输入切片顺序不被修改。
- 凌晨历史响应和 `archived=1` 响应使用统一排序。
