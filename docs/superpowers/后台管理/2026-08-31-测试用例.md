# 后台管理—用户管理一期测试用例清单

本文是开发 TDD 契约；测试工程师应同时对照设计、计划和本文编写自己的用例，方法与编号均不限，并在开发完成后进行二次验证。

## 文档用途

| 谁 | 怎么用 |
| --- | --- |
| 开发 | 每个切片先将对应用例写成失败测试，再实现最小行为 |
| 测试工程师 | 结合设计、计划和本文设计独立验证，不要求复用本文编号或测试方法 |

## 任务 1（Task 1）：管理员认证

| 编号 | 测试落点 | 前置/输入 | 期望结果 |
| --- | --- | --- | --- |
| 权限-AUTH-001 | `backend/flutter_api/admin_service_test.go` | 调用管理员登录，输入 `admin/admin` | 返回非空 Token 和过期时间 |
| 权限-AUTH-002 | `backend/flutter_api/admin_service_test.go` | 输入错误用户名或错误密码 | 返回 `INVALID_CREDENTIALS`，不生成可用 Token |
| 权限-AUTH-003 | `backend/flutter_api/admin_http_test.go` | 无 Token、普通用户 Token、伪造 Token 访问用户列表 | 均返回 `401` |
| 权限-AUTH-004 | `backend/flutter_api/admin_service_test.go` | 使用过期管理员 Token | 返回 `UNAUTHENTICATED` |
| 权限-AUTH-005 | `backend/flutter_api/admin_service_test.go` | 连续登录超过 Token 上限并跨过过期时间 | 过期 Token 被清理，同时有效 Token 不超过 32 个 |

## 任务 2（Task 2）：用户查询和状态管理 API

| 编号 | 测试落点 | 前置/输入 | 期望结果 |
| --- | --- | --- | --- |
| 用户-USER-001 | `backend/flutter_api/admin_http_test.go` | 创建两个普通用户后调用用户列表 | 返回两条用户安全字段，响应不含 `passwordHash`、Token 或设备 ID |
| 用户-USER-002 | `backend/flutter_api/admin_http_test.go` | 以账号或昵称关键词查询 | 只返回匹配用户，`total` 与 `items` 一致 |
| 用户-USER-003 | `backend/flutter_api/admin_http_test.go` | 管理员将 active 用户改为 disabled | 返回更新后的状态；原有普通用户会话随后认证失败 |
| 用户-USER-004 | `backend/flutter_api/admin_http_test.go` | 管理员将 disabled 用户改为 active | 返回更新后的状态；用户可以重新登录 |
| 用户-USER-005 | `backend/flutter_api/admin_http_test.go` | 使用不存在用户 ID 或非法状态 | 分别返回 `404` 或 `400` |
| 用户-USER-006 | `backend/flutter_api/admin_http_test.go` | 调用普通用户公开登录/注册接口 | 原有认证接口行为不变 |
| 用户-USER-007 | `backend/flutter_api/auth_service_test.go` | 普通登录暂停在建会话前，管理员已提交禁用 | 登录返回 `ACCOUNT_DISABLED`，不创建有效会话 |
