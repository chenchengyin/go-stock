# 红策组合筛选与长按说明

> 2026-10-15 同步：当前有6套参考形态和9套独立形态。以下说明以当前规则定义为准；破板独立组合已更新为v3，T0开盘0%～3%是硬性条件。旧v1/v2归档保留各自口径，不能借用为当前版本统计。

## 目标

全部15套组合按“形态条件、T0开盘、统计口径”分段说明。长按规则标签可读到完整条件。策略回归选中组合后直接展示股票列表，不常驻说明卡，避免挤占列表空间和内外两层滚动相互干扰。

## 条件与口径

新增组合要求：

- T-3、T-2 收盘涨停；T-1 涨停破板。
- T-1 振幅 `(最高价-最低价)/T-2收盘价` 为 6%～10%；下影线 `(min(T-1开盘,T-1收盘)-T-1最低价)/T-2收盘价` 不超过 1%。
- 若 T-1 实体收益 `(收盘-开盘)/开盘` ≤ -5%，T-1 收盘涨幅 `(T-1收盘/T-2收盘-1)` 仅允许 `<1%` 或 `[3%,4%)`。
- T0 已确认开盘涨幅为 `0%≤涨幅≤3%`，两端均包含；允许平开，低开或高开超过3%不入选。盘前只展示候选。
- 当前破板规则以 T0 开盘为入场参考，按 T+1 收盘评判；真赚为收益>0%，达标为收益≥2.5%。旧v1的 `0%≤涨幅<5%` 建议和 `18/22=81.8%` 日内观察只属于历史版本，不再作为当前组合说明或统计。

### 全部组合的开盘与评判口径

T0为选股日，T-1/T+1为前后交易日。开盘涨幅统一按 `(T0开盘/T-1收盘−1)×100%` 计算。`0.01%` 下限不包含平开，不得写成 `0%`。

六套参考形态的红策入选分支还要求近7日收盘涨停或T-1破板、T-1成交额≥5亿。参考统计中“不亏率”包含持平，“正收益率”严格大于0%，达标为收益≥2.5%；不得统称为T+1真赚率。

两套连续下跌规则使用最近一次收盘涨停锚点，不能跳过最近涨停借用更早锚点。中阴实体跌幅>2.5%且≤6%，大阴>6%，以昨收为分母；A2规则额外的4.3%跌幅以T-1开盘为分母。

“收跌0%～2%的阴线”按相对昨收的收盘跌幅筛选，不要求分类器的小阴；四组阴线组合也不要求分类为中阴。四组的开盘、收盘、实体都以T-2收盘为分母，各区间下限包含、上限不包含，第3组实体的0%也不包含。

### 新增独立规则：七日深跌后低开（T0）

- 前置累计跌幅：`T−1收盘/T−7收盘−1≤−22.25%`，且 T−7 至 T−1 七个交易日逐日对齐。
- T0 开盘缺口：`(T0日线开盘/T−1收盘−1)×100%`，范围为 `[-4%,-2%)`。
- T−1 振幅：`(T−1最高−T−1最低)/T−2收盘≥7.1%`。阈值只用 T0 前可知数据；2024–2025 年发现，2026 年留出验证。
- 盘前只展示满足历史与 T−1 振幅条件的候选，开盘后才按 T0 缺口范围确认命中；不使用市场宽度过滤。
- 这条规则的统计周期是 **T0 盘中最高价**：历史入场价采用 T0 日线开盘代理；浮盈触及为最高价相对入场价 `>0%`，目标触及为最高价相对入场价 `>2.5%`（不包含2.5%）。不得显示为已实现真赚率；T0买入的A股不能当日卖出，日线最高价不代表实际成交或落袋收益。

历史规则说明沿用对应规则定义作为唯一来源：T0 参考规则说明放在 `t0reference.RuleDefinition`，独立 GOB 说明放在 `redGobRule`。后端把说明随命中项返回，Flutter 只负责解析并展示，不维护第二份规则文案。既有规则表行与默认定义键相同时，以默认定义补充说明；旧 GOB 快照按规则键补充说明。

## 列表行为

- 每个红策命中标签继续使用现有 Flutter `Tooltip` 长按交互。
- 六组内置 T0 参考红策和全部独立 GOB 红策标签显示具体形态、入场开盘要求和评判周期。
- 提示明确列出全部形态条件、开盘边界、入场参考价和统计周期。四组阴线同时保留完整说明与本次命中分组。
- 同一当前规则版本的快照按规则键同步最新名称和说明；历史版本保留原说明，缺失时按对应版本补齐，不重写磁盘归档。

## 不做

- 除已纠正的破板v3开盘范围外，不改其他组合的筛选阈值或统计计算。
- 不将旧破板v1/v2统计混入v3，不改其他策略模块。
- 不混用 T0 日内观察率和红策 T+1 收盘统计。
