
### 任务 3：T+1 目标触发及持续提醒

#### 流程图

```mermaid
flowchart TD
  A[载入前一交易日已确认 EntryClose/Target] --> B[T+1 实时行情轮询]
  B --> C{现价 >= 目标?}
  C -->|否| B
  C -->|是| D[保存当日已触发状态]
  D --> E[列表显示卖出提醒直至当日结束]
```

#### 伪代码

```text
载入本地已确认且属于上一交易日的目标监控项
轮询现价；首次到达目标时记录当日触发
行情回落不清除触发状态；跨日清理过期项目
```

#### 注意点

- 触发按实时报价现价判断；10 秒轮询不能保证观察到两次轮询之间的瞬时触及。
- 本地状态不代表服务器下单或其他设备同步。
- 验证提醒-ALERT-001/002。
