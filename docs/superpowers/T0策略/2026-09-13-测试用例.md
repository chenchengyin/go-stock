# T0 前置形态参考库统一架构测试用例清单

本文是开发 TDD 契约。开发人员按切片先写失败测试再实现；测试工程师同时对照设计、实现计划和本文编写自己的用例，方法与编号均不限，并在开发完成后进行二次验证。

## 文档用途

| 谁 | 怎么用 |
|---|---|
| 开发 | 按任务顺序执行 Red → Green → 回归 |
| 测试工程师 | 以设计、计划和本文为输入，独立设计并执行二次验证 |
