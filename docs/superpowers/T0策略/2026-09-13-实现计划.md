# T0 前置形态参考库统一架构实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 建立保存 T0 原始观察和 T-3～T-1 K 线的通用形态参考库，同时兼容现有普通形态库和旧 T0 接口。

**架构：** 新增独立的 T0 reference 分析模块，分为原始观察、规则定义、规则统计三层。普通形态和数值条件统一编译到同一规则 AST；旧 `t0_pattern_stats` 保留，由适配器负责回退和兼容。

**技术栈：** Go、GORM、SQLite、现有 `backend/analysis/candlepattern`、本地 Gob 日线缓存、Flutter 现有 JSON 模型。

**设计文档：** `docs/superpowers/T0策略/2026-09-13-设计.md`

**开发测试契约：** `docs/superpowers/T0策略/2026-09-13-测试用例.md`

## 全局约束

- 保留现有 `t0_pattern_stats`、旧归档 JSON 和旧 `BuySignal` 语义。
- 严格胜率定义为 `T0 收盘价 > entry_price`；2.5% 达标率和真亏率单独保存。
- `entry_price` 与日线 `t0_open` 分开；历史 Gob 使用 `daily_open`，实时竞价使用 `auction_0925`。
- 原始观察按 `source_batch` 保留版本，同一股票日最多一个活动版本。
- 规则只读取 T-3～T-1 和 T0 竞价字段，不能读取 T0 收盘结果。
- 当前研究优先级为 A：N≥20 且严格胜率≥65%；B：N=10～19 且严格胜率≥65%。
- 深红只使用明确指定的逻辑；当前保留 `任意K线＋涨停＋跌停`、`T-2 低开 + T-1 开盘涨幅≥3% + T-1 振幅≥8%` 和既有“两连涨停 + T-1 非一字 + T-1 开盘涨幅≥3% + T0 竞价”三套逻辑，不能按小样本胜率自动扩散；`T-2 振幅≥8% + T-1 开盘涨幅≥8% + T-1 振幅<4%` 暂作次级候选。
- 使用当前 `dev` checkout 直接开发，保留工作区中与本功能无关的既有变更，不执行清理或重置。

- Produces: `CompiledRule`、`RuleHit`、规范化 `rule_key`。

**流程图：**

```text
condition_json + entry_json
    ↓
解析并校验白名单字段/操作符
    ↓
规范化 all 子条件 + 规则版本
    ↓
编译统一 AST
    ↓
PreT0View + EntryView → 命中/不命中
```

**伪代码：**

```text
compile(definition):
  validate(condition_json, entry_json)
  canonical = canonicalize(condition_json, entry_json, version)
  return CompiledRule{Key: sha256(canonical), AST: parse(canonical)}

match(rule, preT0, entry):
  evaluate AST fields from -3/-2/-1 only
  evaluate entry_json against entry_gap
  return true only when both pass
```

**注意点：**

- `sequence` 只是规则分类，必须转换到同一个 AST，不得保留第二套匹配实现。
- 支持当前所需字段：`close_type`、`is_one_word`、`amplitude`、`open_ret`、`close_ret`。
- `all` 条件顺序不影响 key；`sequence` 顺序必须保留。
- T0 close/high/low 不进入匹配视图。

**伪代码：**

```text
enrich(result):
  legacy = enrichResultWithPattern(result)
  observation = lookupActiveObservation(date, code)
  if observation missing: return legacy
  hits = MatchReferenceRules(preT0View(observation), entryView(observation), enabledRules)
  result.ReferenceHits = topThree(hits)
  result.ReferenceTier = highestTier(hits)
  return result
```

**注意点：** 新库查询失败时回退旧逻辑；新研究等级不改变 `BuySignal`、`命中条件`、`重点标红`。排序实现必须同时修改后端和 Flutter，保持历史接口响应顺序测试。
