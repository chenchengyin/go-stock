# 小阴收盘买入与目标触发提醒设计

## 背景与目标

红策已有“涨停→小阴线”独立形态按 T0 开盘入场。新增一个独立版本：沿用其 T−2/T−1 形态条件，但要求 T0 最终收阴，以 T0 收盘价为入场参考；T+1 现价达到 T0 收盘价上方 2.5% 时，在红策列表显示卖出提醒。

## 非目标

- 不修改已有红策规则、命中、统计或历史口径。
- 不自动下单；提醒仅供人工处理。
- 不把事后 T+1 最高价回测当作实时可成交收益。

## 权限

沿用红策现有模块权限。

## 页面 / 接口（用户可观察行为）

- 14:30 后，满足既有红策前置形态的股票进入尾盘候选，并持续用实时行情判断当前价格是否低于开盘价。
- 收盘确认 T0 阴线后记录 T0 收盘价和 +2.5% 目标价；候选状态明确标为待收盘确认。
- T+1 红策列表监控这些目标；现价达到或超过目标时出现“卖出”提醒并保持到当日结束，不自动下单。
- 盘中报价触发与历史日线最高价触及率分开表达。

## 架构与数据

- 复用 Gob 规则历史形态匹配、红策候选 API、现有批量实时行情接口和列表刷新周期。
- 新规则使用独立 rule key/version、`daily_close` 入场来源及单独的目标触及统计；旧规则继续使用 `realtime_open` / `daily_open` 和 T+1 收盘统计。
- T0 尾盘候选与 T+1 监控状态需跨页面刷新保留；目标触发状态至少保留在当前客户端当日状态中。

## 错误与安全

- 14:30 行情为临时观察值，不能代替官方收盘价；收盘数据缺失时保持待确认，不生成目标价。
- 实时行情缺失时不推断触发，不清除已触发状态。
- 目标价按 T0 收盘价 × 1.025 计算后向上取到 0.01 元报价单位，确保触发价不低于 2.5% 涨幅。

## 验收标准

- 旧规则 key、入场来源和统计不变。
- 新规则仅在 T−2/T−1 形态匹配且 T0 收盘低于开盘时确认。
- T+1 现价首次达到目标价后，红策列表显示持续卖出提醒，刷新页面后当日状态仍在。
- 未达到目标、行情缺失、历史/周末页面不会误显示提醒。
